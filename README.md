# 🍰 Discord Cake Bot

 Discord-бот, кидающий во входящих в чат тортом на сервере. Бот позволяет встречать новичков случайными фразами и анимированными GIF-изображениями летящих тортов, а также добавляет интерактивную кнопку, с помощью которой любой желающий может запустить тортом в пользователя!

---

## ✨ Функционал
* **Интерактивные приветствия:** Автоматически встречает новых участников на сервере случайным текстовым приветствием и случайной GIF-анимацией.
* **Кнопка «Кинуть тортом!»:** К приветствию прикрепляется кнопка. При нажатии на неё бот отправляет в чат анимацию броска торта в выбранного участника.
* **Динамическая настройка:** Администраторы серверов могут самостоятельно устанавливать канал для приветствий прямо через текстовую команду.
* **База данных:** Настройки каналов для каждого сервера сохраняются в JSON-файл с защитой от повреждений при чтении/записи.
* **Логирование:** Отслеживание ошибок (Traceback) в консоли для удобной отладки.

---

## 🛠️ Команды бота

* `!настроить` — устанавливает текущий текстовый канал в качестве канала приветствий. *(Доступно только для Администраторов сервера)*.
* `!торт` — отправляет праздничное приветствие с тортом и кнопкой броска в автора команды. *(Доступно всем участникам)*.

---

## 📦 Требования и Зависимости
Для работы бота необходим **Python 3.8+** и следующие библиотеки:
* **`discord.py`** — для взаимодействия с API Discord.
* **`python-dotenv`** — для безопасного хранения токена в переменных окружения.

## 🚀 Установка и запуск

### 1. Клонирование и создание виртуального окружения

**На Linux / macOS (Bash):**
```bash
python3 -m venv venv
source venv/bin/activate
pip install discord.py python-dotenv
```

**На Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install discord.py python-dotenv
```

**На Windows (Командная строка CMD):**
```cmd
python -m venv venv
.\venv\Scripts\activate.bat
pip install discord.py python-dotenv
```

---

### 2. Настройка переменных окружения
Создайте файл **`.env`** в корневой директории вашего проекта и укажите в нём токен вашего бота:
```text
DISCORD_TOKEN=ваш_секретный_токен_бота_сюда
```

### 3. Подготовка медиа-файлов
Создайте в корне проекта папку с именем `gifs` и загрузите в неё любые изображения формата `.gif` (анимации летящих тортов, взрывов и праздничной тематики). Бот будет автоматически выбирать их случайным образом.

### 4. Запуск бота

**На Linux / macOS:**
```bash
python3 main.py
```

**На Windows (PowerShell / CMD):**
```cmd
python main.py
```

## 📁 Структура проекта

```text
├── gifs/                 # Папка с GIF-анимациями тортов (создаётся локально или на сервере с ботом)
├── .env                  # Секретный файл с токеном Discord (скрыт)
├── .gitignore            # Файл исключений для системы контроля версий Git
├── bot_events.py         # Обработка событий Discord (on_ready, on_member_join, on_message)
├── config.py             # Константы, загрузка путей, .env и скрытие файлов в Windows
├── database.py           # Модуль для чтения и записи настроек серверов (в settings.json)
├── main.py               # Главная точка входа для инициализации и запуска клиента
├── settings.json         # Хранилище привязок каналов к серверам (создается автоматически)
└── ui_components.py      # Интерфейсные компоненты Discord (Класс кнопки CakeButton)
```
